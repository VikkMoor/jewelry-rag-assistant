# 💍 Jewelry RAG Assistant

AI-консультант ювелирного магазина, реализованный с использованием технологии **Retrieval-Augmented Generation (RAG)**.

Проект выполняет семантический поиск по базе знаний и каталогу товаров, формирует контекст и генерирует ответ с помощью языковой модели **Llama 3.1**, позволяя получать рекомендации на основе данных магазина, а не заранее подготовленных шаблонов.

---

## 🚀 Возможности

- семантический поиск по базе знаний магазина;
- поиск подходящих товаров в каталоге;
- объединение результатов поиска в единый контекст (RAG);
- генерация ответов с помощью модели **Llama 3.1** через **Groq API**;
- рекомендации украшений с учетом пользовательского запроса;
- ответы на вопросы по уходу за ювелирными изделиями;
- демонстрация полного цикла работы Retrieval-Augmented Generation.

## 🧠 Архитектура RAG

Проект реализует классическую схему Retrieval-Augmented Generation:

1. Пользователь вводит запрос.
2. Выполняется семантический поиск по базе знаний.
3. Выполняется поиск подходящих товаров в каталоге.
4. Формируется единый контекст.
5. Контекст передается языковой модели **Llama 3.1**.
6. Пользователь получает ответ, основанный на найденной информации.

Такой подход позволяет модели отвечать, используя данные конкретного магазина, а не только собственные знания.
